# 工具链与思维链优化器 (Tool-Think Optimizer)

> **元技能** — 让 AI 更聪明地使用工具和推理能力

## 是什么

`tool-think-optimizer` 是一个 AI Agent Skill，它优化 AI 在多步骤任务中的**工具调用链**和**思维推理链**。

## 效果

经过 3 轮迭代、9 个压测场景验证：

| 指标 | 无 Skill | 有 Skill | 改善 |
|------|:---:|:---:|:---:|
| 平均工具调用轮数 | 6.9 | 3.1 | **-55%** |
| 并行调用占比 | 0% | 4.6/任务 | ♾️ |
| 断言通过率 | 15% | 100% | +85pp |

## 核心策略

- 🔀 **批量并行** — 识别无依赖的调用，同一轮发出
- 🔗 **依赖拓扑** — 按依赖图排序，避免无效等待
- 🎯 **工具矩阵** — 6 种需求的最优工具选择
- 🔍 **假设驱动** — 形成假设→验证→修正循环
- ⚡ **5秒自检** — 每次调用前 5 个必问问题

## 5 个实战模式

| 模式 | 场景 | 预期轮数 |
|------|------|:---:|
| A: 代码调试 | 错误定位+修复 | 4-5 |
| B: 项目探索 | 理解架构 | 3-4 |
| C: 多源检索 | 搜索+汇总 | 2-4 |
| D: 批量操作 | 多文件修改 | 3-4 |
| E: 依赖分析 | 循环导入/ImportError | 3-5 |

## 安装

将 `tool-think-optimizer.skill` 安装到你的 AI Agent 技能目录。
